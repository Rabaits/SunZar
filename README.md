SunZar — VK чат-бот с прогнозом погоды

Учебный проект: чат-бот для сообщества ВКонтакте, который показывает текущую погоду и почасовой прогноз на день. 
Данные берутся из Яндекс.Погоды (GraphQL API), кэшируются в SQLite через peewee, а бот работает на библиотеке simplevk (Long Poll).

Возможности:
/hour — текущая погода (температура и состояние)
/day — почасовой прогноз на 24 часа вперёд
/help — список команд

Погода хранится в локальной БД и обновляется фоновым потоком раз в час
Состояния погоды переводятся с английского (API) на русский

Стек:
Python 3.10+
simplevk — VK Long Poll API
peewee — ORM для SQLite
requests — запросы к GraphQL API Яндекс.Погоды
SQLite — локальное хранилище прогноза
